# Verbatta — downloads

Instaladores do **Verbatta**, aplicativo para Windows que transcreve gravações de sessões e reuniões
e gera minutas de ata, **tudo offline**: áudio e textos não saem do computador.

## Instalar

1. Em [Releases](../../releases/latest), baixe `Verbatta-Instalador-<versão>.exe`.
2. Execute o instalador. Se o Windows exibir "O Windows protegeu o computador", clique em
   **Mais informações** e depois em **Executar assim mesmo**.
3. Ao abrir o Verbatta, informe o código de licença fornecido à sua instituição.

Para conferir a integridade do arquivo, compare o SHA-256 dele com o do arquivo `.sha256` da mesma versão.

## Avisos de software livre e código-fonte

O Verbatta é software proprietário e usa bibliotecas livres (LGPL), entre elas Qt/PySide6, PyAV e FFmpeg.
O instalador traz os textos das licenças e uma página de avisos. O código-fonte das versões dessas
bibliotecas usadas no Verbatta está disponível:

- **PyAV 15.1.0 e FFmpeg 7.1.5** (versão LGPL, sem x264/x265): anexos de cada versão em [Releases](../../releases).
- **Qt 6.12.0**: https://download.qt.io/official_releases/qt/6.12/
- **PySide6 6.12.0**: https://code.qt.io/cgit/pyside/pyside-setup.git
